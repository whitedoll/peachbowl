# 섹션별 카피 작법

상세페이지는 **위에서 아래로 읽으며 설득되는 구조**다. 각 섹션은 앞 섹션이 만든
궁금증에 답해야 한다. 순서를 바꾸지 않는다.

## 톤 기본값

- 존댓말, 담백하게. 느낌표는 페이지 전체에서 3개 이하
- 한 문장 40자 이내. 두 줄 넘어가면 끊는다
- 형용사보다 **숫자와 사실**. "아주 가벼운" 대신 "230g"
- 이모지는 쓰지 않는다 (스마트스토어 캡처 이미지에서 폰트가 깨진다)
- 사용자가 톤을 지정했다면(감성/실용/프리미엄) 그것을 우선한다

## 1. HERO — 최상단 후킹

키 이미지 위 또는 아래에 짧은 카피 2줄.

- 1줄: 이 상품이 해결하는 **상황** (기능이 아니라 장면)
- 2줄: 상품명 + 핵심 스펙 한 가지

```
아침마다 뭘 입을지 고민하는 시간
─ 데일리 코튼 셔츠 · 40수 순면
```

금지: "안녕하세요 고객님", "저희 제품은", 브랜드 자기소개로 시작하는 것

## 2. FOR — 이런 분께 추천

체크 리스트 3~4개. 상품 자랑이 아니라 **구매자의 상태**를 쓴다.

```
□ 하루 종일 입어도 편한 셔츠를 찾고 계신 분
□ 다림질에 시간 쓰기 싫으신 분
□ 사무실과 주말 모두에 어울리는 옷이 필요하신 분
```

## 3. POINT — 핵심 소구점 3개

가장 중요한 섹션. 소구점 하나당 [번호 + 짧은 제목 + 설명 2~3줄 + 근거 이미지] 세트.

- 소구점은 **사진으로 증명 가능한 것**만 고른다. 사진에 근거가 없으면 그 소구점은 뺀다
- 제목은 8자 내외 명사구. 설명은 그 제목을 풀어쓴다
- 3개를 억지로 채우지 않는다. 확실한 2개가 애매한 3개보다 낫다

```
POINT 01   구김이 덜한 원단
장시간 앉아 있어도 앞판에 접힘 자국이 크게 남지 않습니다.
세탁 후 널어두면 다림질 없이 입을 수 있습니다.
```

## 4. DETAIL — 디테일 컷

클로즈업 이미지 + 한 줄 캡션. 캡션은 이미지에 실제로 보이는 것만 설명한다.
봉제, 마감, 단추, 라벨, 질감 등.

## 5. SIZE / OPTION — 사이즈·구성  <!-- 자료 없으면 섹션 삭제 -->

표로 정리. 측정 방식(단면/전체)과 오차 범위를 반드시 병기한다.

```
단위: cm / 측정 방법에 따라 1~2cm 오차가 있을 수 있습니다.
```

## 6. INFO — 상품 정보

`references/compliance.md` 의 품목별 필수 항목 표. 2열 표(항목 / 내용).
빈 항목은 `※ 판매자 확인 필요`.

## 7. DELIVERY — 배송 안내

사용자가 알려준 조건만 쓴다. 모르면 아래 골격에 확인 필요 표시.

- 출고: 결제 확인 후 ○영업일 이내
- 택배사 / 배송비 / 무료배송 기준
- 도서산간 추가비
- 주말·공휴일 제외 문구

## 8. RETURN — 교환·반품 안내

- 신청 기간: 상품 수령 후 7일 이내 (전자상거래법 기본값, 판매자가 더 길게 줄 수는 있음)
- 반품 배송비 부담 기준 (단순 변심 / 상품 하자)
- 교환·반품이 **불가한** 경우: 사용·세탁·훼손, 시간 경과로 재판매가 어려운 경우,
  주문제작 상품 등 — 해당하는 것만 남긴다

## 9. NOTICE — 주의사항

모니터 색상 차이, 수작업 상품의 개체차, 소재 특성상 나타나는 현상 등
**미리 알리면 클레임이 줄어드는 것**을 솔직하게 쓴다. 이 섹션이 신뢰를 만든다.

## 자주 하는 실수

| 실수 | 대신 |
|---|---|
| 사진에 안 보이는 기능을 설명함 | 사진이 있는 것만 소구점으로 |
| 소구점 5~6개 나열 | 3개로 압축 |
| "고급스러운 소재" 같은 빈 형용사 | 소재명 + 중량 + 촉감 묘사 |
| 브랜드 스토리를 최상단에 | 필요하면 맨 아래 짧게 |
| 표 안에 긴 문장 | 표는 단어, 문장은 본문에 |
