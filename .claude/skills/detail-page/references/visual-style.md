# 비주얼 스타일 — 피치보울

상품 15개 상세페이지 전수 관찰 + 사진 색분포 측정 (2026-08-19).
`brand-voice.md` 가 "무슨 말을 쓰나"라면 이 문서는 "어떻게 보이나"다.

---

## 1. 사진 톤 (측정값)

전 상품에서 화면을 지배하는 색은 **15~45° 저채도 웜 톤**(피부 + 따뜻한 뉴트럴 배경)이다.
15개 중 14개에서 1~2위를 차지했다. 채도 있는 색은 **제품 자체에서만** 나온다.

| 라인 | 평균 밝기 |
|---|---|
| 속옷 (UNDERWEAR) | **L 0.83** — 밝고 하이키 |
| 수영복 (SWIMWEAR) | **L 0.69** — 한 단계 낮음, 야외광 |

→ 새 사진을 고를 때 **속옷은 더 밝게, 수영복은 살짝 눌러서** 고른다.
→ 배경에 채도 있는 색이 들어가면 이 브랜드처럼 안 보인다. 배경은 무채색이거나 웜 뉴트럴.

제품 색으로만 등장한 액센트: 레드 `0°` · 블루 `195~210°` · 네이비 `240°`

---

## 2. 모델 연출

- **얼굴을 보여주지 않는다.** 턱 아래 또는 코 아래에서 크롭한다.
  전신컷에서도 머리가 프레임 위로 잘리거나, 손·모자·팔로 얼굴이 가려진다.
  이게 이 브랜드에서 가장 일관된 규칙이다.
- 프레이밍은 **가슴~허벅지 중심**. 상반신 클로즈업과 무릎 위 전신을 번갈아 쓴다.
- 포즈는 서 있는 정면 → 측면 → 뒷면 순으로 돈다. 앉은 컷(라탄 체어, 침대)을 1~2장 섞는다.
- 자연광. 플래시나 강한 그림자를 쓰지 않는다.
- 손은 허리·머리·옷 끈에 두어 비어 보이지 않게 한다.

## 3. 로케이션 레퍼토리

관찰된 배경은 이 안에서 반복된다. 새 촬영도 여기서 고른다.

| 무드 | 배경 |
|---|---|
| 실내 스튜디오 | 화이트 월, 나무 바닥, 라탄 원형 장식, 프렌치 몰딩 도어 |
| 호캉스 | 호텔 욕실, 욕조, 창가 시티뷰, 우드 도어, 야자수 + 시멘트 벽 |
| 옥상·베란다 | 도시 스카이라인, 난간, 한낮 직광 |
| 물가 | 수영장 민트 타일, 해변 모래, 바다 |
| 현장 | 페스티벌·워터밤 인파 (수영복 한정) |
| 침실 | 흰 침구, 크리스마스 트리, 와인 (속옷 한정) |

## 4. 소품

라탄백 · 크로셰백 · 밀짚모자 · 선글라스 · 조리 · 플루메리아 꽃 · 선크림 ·
체크 돗자리 · 데님 쇼츠 · 흰 시스루 랩스커트 · 핑크 옷걸이

소품은 **한 컷에 1~2개까지**. 제품보다 눈에 띄면 안 된다.

---

## 5. 사진 위 주석 — 3가지 도구

이 브랜드는 설명을 본문으로 빼지 않고 **사진 위에 직접 얹는다.** 세 방식이 섞여 쓰인다.

### (1) 포인트 라벨 — 상품마다 형태가 다르다

| 형태 | 표기 | 위치 |
|---|---|---|
| 핑크 체크박스 + 흰 굵은 산세리프 | `Peach Check01` | 사진 중앙 |
| 손글씨풍 컬러 아웃라인 | `Peachy Point!` | 자유 배치 |
| 검정 알약 배지 + 흰 글씨 | `PEACH POINT 1` | 하단 좌/우 |

**개념은 고정(번호 붙인 포인트 3개), 시각 처리는 상품마다 고른다.**
새 상품에서는 사진 밝기에 맞춰 고른다 — 밝은 사진엔 검정 배지, 어두운 사진엔 흰 글씨.

### (2) 손글씨 컬러 텍스트
사진 위에 핑크·보라 손글씨로 짧은 구절. `상체를 여리여리하게 크롭 시스루 가디건`,
`데님쇼츠, 조거팬츠 등 다양한 코디 가능`, `Colji embo strap`

### (3) 도형 지시
- **빨간 화살표** 로 부위를 직접 가리킨다 (2개까지)
- **흰 점선 원** 으로 디테일을 감싼다
- **흰 점선 직선** 으로 라인을 표시한다

도형만 쓰고 라벨을 안 붙이는 컷도 있다. 이때 설명은 사진 바로 아래 컬러 캡션으로 단다.

---

## 6. 플랫레이 (제품컷)

- 누끼가 아니라 **실제 천 위에 놓고 찍는다.** 흰 린넨·침구, 수영장 타일, 모래, 체크 돗자리
- 상의와 하의를 위아래로 배치, 끈은 자연스럽게 흘려둔다
- **옷걸이에 걸어 찍은 컷**을 마지막에 한 장 넣는 경우가 많다 (앞·뒤 각 1장)
- 컬러가 여러 개면 컬러별로 같은 구도를 반복한다

## 7. 페이지 레이아웃

```
상품정보제공고시 표      작은 글씨, 왼쪽정렬, 맨 위
시즌 배너                안녕, 봄 / HELLO, SPRING ~50% OFF  (기간만 바꿔 전 상품 재사용)
메인 연출컷
말풍선 + 카피 블록
포인트 컷 3개            라벨 또는 도형 주석 + 아래 캡션
COLOR / SIZE            영문 이탤릭 + 밑줄 소제목
MODEL CUT               연출컷 연속 나열, 캡션 거의 없음
DETAIL CUT              플랫레이 + 옷걸이컷
SIZE TIP                말풍선, 빨강 강조
안내문 5블록
관련 태그
```

- 가로 **860px** (실측 859~893px). 이미지는 폭을 꽉 채운다.
- 이미지 사이 여백은 거의 없다. 사진을 연속으로 붙여 흐르게 한다.
- 텍스트 블록에서만 위아래로 크게 숨을 준다.
- 원형으로 크롭한 컷을 가끔 한 장 섞는다 (거울 셀피 등).

### 컷 개수 감각

전체 상세페이지 세로 길이는 **17,000~29,000px** (860px 폭 기준).
사진 25~40장. 짧은 상품(커버업)은 5,400px 로 확 줄이기도 한다.
**분량을 억지로 채우지 않는다** — 보여줄 게 적으면 짧게 끝낸다.

---

## 8. 새 페이지 만들 때 체크

- [ ] 얼굴이 나온 컷이 없다 (턱 아래 크롭)
- [ ] 배경에 제품 색 말고 채도 높은 색이 없다
- [ ] 속옷이면 밝게(L 0.8 이상), 수영복이면 조금 눌러서
- [ ] 포인트 라벨 3개의 시각 형태가 한 페이지 안에서 통일돼 있다
- [ ] 플랫레이가 누끼가 아니라 천 위에 놓인 컷이다
- [ ] 사진 위 주석이 한 컷에 2개를 넘지 않는다
- [ ] 소품이 제품보다 튀지 않는다

---

## 9. 이 문서의 한계

색 수치는 상세페이지 캡처 전체에서 뽑은 값이라 텍스트 영역과 배너가 섞여 있다.
사진만 따로 측정한 값이 아니므로 **경향으로만** 쓰고, 절대값으로 보정하지 않는다.
로케이션·소품 목록은 관찰된 15개 상품 기준이라 앞으로 늘어날 수 있다.
